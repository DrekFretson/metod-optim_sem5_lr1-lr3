# Лабораторная работа №2 — транспортная задача

Модель минимизирует совокупные транспортные затраты при точном выполнении спроса магазинов, ограниченных запасах складов и запрещённых связях. Переменные создаются только для разрешённых дуг; запрещённые маршруты исключены из модели, а в плане для них сохраняется нулевой поток.

Параметры варианта 19: $N=5$, $Q=1$, $Y=26$, группа 517, $V=19$, seed `10105`.

## Состав

- `run.py` — полный воспроизводимый конвейер.
- `data/generated/` — CSV складов, магазинов, тарифов и доступности маршрутов, плюс метаданные генерации.
- `data/scenarios/` — JSON базового, дефицитного и стрессового экспериментов.
- `src/data_generation.py` — генерация и LP-проверка выполнимости сети.
- `src/data_loader.py` — проверки входных CSV.
- `src/model.py` — матрицы LP для разрешённых маршрутов.
- `src/solver.py` — вызов SciPy/HiGHS и статусы.
- `src/validation.py` — независимый пересчёт сохранённого плана.
- `src/sensitivity.py` — теневые цены и их проверка малыми изменениями RHS.
- `src/experiments.py` — сценарии, анализ маршрутов и сравнение со всеми разрешёнными дугами.
- `src/reporting.py` — пять графиков и отчёт.
- `results/` — планы, использование складов, обслуживание спроса, статусы и проверки.
- `experiments/` — CSV сценариев, теневых цен и анализа маршрутов.
- `plots/` — пять иллюстраций отчёта.
- `logs/solver.log` — журнал HiGHS.
- `reports/report.md` — подробный итоговый отчёт.

## Окружение и запуск

Используются закреплённые версии NumPy 2.3.3, Pandas 2.3.3, SciPy 1.16.2, Matplotlib 3.10.7 и tabulate 0.9.0 (Python 3.11–3.14).

```bash
python -m pip install -r requirements.txt
python run.py
```

Команды выполняются из `lr-2`. Первый запуск генерирует CSV с `numpy.random.default_rng(10105)`; дальнейшие запуски используют сохранённые исходники. Конфигурации сценариев и результаты обновляются автоматически. Сценарий shortage подбирает сокращение запаса, которое меняет стоимость или приводит к обоснованной недопустимости. Стресс одновременно уменьшает два запаса, увеличивает два спроса и закрывает использованный маршрут, если у магазина остаётся альтернатива.

## Модель

Для разрешённых маршрутов $A$ используется непрерывная LP:

$$\min \sum_{(i,j)\in A}c_{ij}x_{ij},\quad
\sum_jx_{ij}\le s_i,\quad\sum_ix_{ij}=d_j,\quad x_{ij}\ge0.$$

Потоки агрегированы за период, поэтому допускают дробные значения. Для физических неделимых партий может потребоваться целочисленная модель.
