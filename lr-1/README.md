# Лабораторная работа №1

## Назначение

Индивидуальное задание варианта 19: минимизация суммарных отходов при раскрое труб. Параметры: $N=5$, $Q=1$, $Y=26$; по формуле получается $V=19$, seed генератора — `10105`.

Модель является усреднённой непрерывной LP. Целевая функция минимизирует отход материала, для каждого заказа действует точное равенство спроса, для каждого типа труб — ограничение запаса. Переменные количества труб по схемам не имеют целочисленных ограничений.

## Структура

- `run.py` — полный конвейер.
- `data/generated/` — исходные CSV, полный список схем и метаданные генерации.
- `data/scenarios/` — JSON-описания трёх сценариев.
- `src/` — генерация и загрузка данных, схемы и LP, решатель, независимая проверка, анализ чувствительности, эксперименты и отчёт.
- `results/` — результаты сценариев и сравнения методов.
- `experiments/` — сводные CSV сценариев, теневых цен и benchmark.
- `plots/` — графики.
- `reports/report.md` — итоговый отчёт.
- `logs/solver.log` — журнал запусков HiGHS.

## Библиотеки

NumPy 2.3.3 используется для генератора и вычислений, Pandas 2.3.3 — для таблиц, SciPy 1.16.2 `optimize.linprog` с HiGHS — для LP, Matplotlib 3.10.7 — для графиков. Версии закреплены в `requirements.txt`; поддерживается Python 3.11–3.14 (полный запуск выполнен на Python 3.14.4).

## Порядок работы

При первом запуске создаются исходные данные; затем проверяются входы, исчерпывающе перечисляются допустимые схемы при kerf=0, решаются базовый, дефицитный и стрессовый сценарии, независимо проверяются ограничения и цель, извлекаются оценки HiGHS и проверяются малыми изменениями RHS. Методы `highs-ds` и `highs-ipm` запускаются по семь раз. В конце формируются графики и отчёт.

Из корня проекта:

```bash
python -m pip install -r requirements.txt
cd lr-1
python run.py
```

Пути вычисляются относительно файлов проекта. Результаты доступны в `results/`, `experiments/`, `plots/`, `logs/`; отчёт — в `reports/report.md`.
