# lin-prog_lr1-lr3

Учебный проект по дисциплине «Методы оптимизации. Линейное программирование».

## Лабораторные

- `lr-1` — лабораторная №1: усреднённая LP-модель минимизации отходов при резке труб. Отчёт: [`lr-1/reports/report.md`](lr-1/reports/report.md).
- `lr-2` — транспортная LP-модель с запрещёнными маршрутами; запуск из `lr-2`: `python run.py`. Отчёт: [`lr-2/reports/report.md`](lr-2/reports/report.md).
- `lr-3` — TODO: лабораторная работа ещё не реализована.

Индивидуальные параметры: $N=5$, $Q=1$, $Y=26$, $V=19$, seed `10105`.

## Установка и запуск

Требуется Python 3.11–3.14. Зафиксированы NumPy 2.3.3 и SciPy 1.16.2 (текущая среда запуска: Python 3.14.4). Из корня проекта:

Установите зависимости один раз, затем запустите нужную лабораторную из её папки:

```bash
python -m pip install -r requirements.txt
cd lr-1 && python run.py
cd ../lr-2 && python run.py
```

Каждая работа сохраняет собственные входные данные, результаты, графики и отчёт в своей папке. Исходные CSV создаются при первом запуске и затем используются повторно.
