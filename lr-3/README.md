# Лабораторная работа №3 — серверы и задачи

Вариант 19: бинарное назначение задач вычислительным серверам при лимите включённых серверов. Параметры: $N=5$, $Q=1$, $Y=26$, группа 517, $V=19$, seed `10105`.

## Модель

Минимизируется сумма стоимостей $c_{ij}x_{ij}$. Переменные $x_{ij}$ и $y_i$ бинарные: задача целиком назначается одному серверу, сервер включён при наличии хотя бы одной задачи. Ограничение $\sum_i y_i\le K$ задаёт лимит. Отдельные фиксированные затраты включения и ограничения вычислительной мощности не используются.

## Файлы и результаты

- `run.py` — полный запуск из этой папки.
- `data/generated/` — CSV серверов, задач, матрица стоимостей и метаданные с фактическими версиями библиотек.
- `data/scenarios/` — конфигурации baseline, shortage и stress; последние два сценария записываются с фактическими отключёнными серверами и K.
- `src/` — генератор, загрузчик, MILP-модель, HiGHS-решатель, независимая проверка, эксперименты и отчётность.
- `results/` — назначения, обе группы переменных, загрузка, solver info и независимые проверки для сценариев и каждого K.
- `experiments/` — сравнение сценариев и анализ K.
- `plots/` — пять графиков назначения, загрузки, стоимостей, лимита K и сценариев.
- `reports/report.md` — итоговый отчёт.
- `logs/solver.log` — журнал вызовов MILP.

## Окружение и запуск

Закреплены NumPy 2.3.3, Pandas 2.3.3, SciPy 1.16.2, Matplotlib 3.10.7, tabulate 0.9.0. Запуск выполняется из `lr-3`:

```bash
python -m pip install -r requirements.txt
python run.py
```

Первый запуск создаёт исходные CSV через `numpy.random.default_rng(10105)`; повторные запуски читают сохранённые данные. Сценарий shortage снижает K и отключает наиболее загруженный сервер базового плана. Stress уменьшает K ещё сильнее и отключает два наиболее загруженных сервера. Анализ зависимости стоимости от K выполняется для значений 3–8 и проверяет монотонность.
